# Sipling assets

## Your avatar
Drop your animated avatar here — Sipling picks the **first** file it finds, in order:

1. `avatar.webm`  ← best: transparent background + small size
2. `avatar.mp4`   ← great: your Gemini/Veo video export
3. `avatar.gif`
4. `avatar.png` / `avatar.jpg` (static fallback)

Tips: a **short seamless loop** (2–4s), roughly square framing, and a **transparent `.webm`**
for a true no-box floating buddy. With no avatar, Sipling shows its logo as a placeholder.

## Notification sounds (`notification/`)
The sounds the user can choose from in **Settings → Notification sound**:

| File | Setting label |
| --- | --- |
| `notification/cute-twinkle.wav` | Cute Twinkle (default) |
| `notification/positive-twinkle.wav` | Positive Twinkle |
| `notification/double-tone.wav` | Double Tone |

To add another: drop a `.wav`/`.mp3` in `notification/`, then add an entry to `SOUND_FILES`
in [`src/main.js`](../src/main.js) **and** `SOUNDS` in [`src/settings.js`](../src/settings.js)
(same key). Sounds from [tunetank.com](https://tunetank.com).

## Fonts (`fonts/`)
Bundled woff2 (offline-safe, no webfont CDN): **Fredoka** (display) + **Nunito** (body),
declared via `@font-face` in [`src/tokens.css`](../src/tokens.css). Sourced from Fontsource.

## Generated icons
- `trayTemplate.png` / `@2x` — menu-bar icon, generated by `npm run gen:icons` (do not edit by hand).
- `icon.png` — app icon for installers (add a 512×512+ PNG; optional).
